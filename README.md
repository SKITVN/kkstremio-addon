Five catalogs only:
- Phim mới
- Phim bộ
- Phim lẻ
- Phim chiếu rạp
- Hoạt hình

## Render
Build: `npm install`
Start: `npm start`

Manifest:
`https://YOUR-RENDER-DOMAIN/manifest.json`

## Important
This build uses a new addon ID (`community.kkphim.final`) to avoid Stremio retaining an older manifest. Remove the previous KKPhim addon before installing this one.
